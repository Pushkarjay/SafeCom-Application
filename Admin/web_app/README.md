# SafeCom Admin Web App

The primary control panel for managing the SafeCom CCTV service platform. Built with React 18 + TypeScript + Vite + Zustand.

## Sub-projects

| Directory | Purpose | Status |
|-----------|---------|--------|
| `admin-dashboard/` | Full-featured admin dashboard | ✅ Active |
| `planning_and_progress/` | Planning docs for admin web | ✅ Active |

## Features

- **Dashboard:** Real-time metrics, system health, revenue tracking
- **Service Catalog:** Full tree builder with infinite nesting, categories, setups, branches
- **Product Management:** Master product CRUD, pricing, variants
- **Recommendation Engine:** Admin-controlled quantity auto-mapping (v1.3.0)
- **Customer Management:** View, edit, and manage customer accounts
- **Technician Management:** Assign, monitor, track performance
- **Jobs Management:** Lifecycle tracking, invoice generation, PDF export
- **Payment Management:** Razorpay integration, transaction history
- **CMS:** Server-driven UI layout management, promo banners, serviceable areas
- **Mobile Preview:** Dual phone frames (customer + employee) with SDUI injection
