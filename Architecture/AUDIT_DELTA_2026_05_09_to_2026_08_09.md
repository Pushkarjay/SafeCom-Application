## 2. Backend Server Changes

### Routes: 17 → **25 route files** (+8 services, 2 middleware)

New route modules since the last architecture snapshot:

| New route file | Purpose |
|----------------|---------|
| `addresses.ts` | Customer saved-address CRUD + set-default (`/api/customers/:customerId/addresses/*`) |
| `homeCms.ts` | Home page CMS (promo banners, sections) — public read, admin write |
| `installationAdmin.ts` | Installation tree builder (categories, setups, products, branches, nodes, clone, club) |
| `maintenance-plans.ts` | AMC/Maintenance plan catalog (`catalog_maintenance_plans`) |
| `products.ts` | Product catalog CRUD + pricing |
| `razorpay.ts` | Razorpay order creation + signature verification |
| `recommendations.ts` | Recommendation add-ons |
| `sduiAdmin.ts` | SDUI layout + feature-flag admin |
| `serviceability.ts` | Serviceable-area check + area CRUD (shared with admin + mobile map) |
| `servicesAdmin.ts` | Dynamic service tree builder (categories/setups/products/nodes/branches, quantities, dynamic fields, rename, clone, club) |
| `users.ts` | Customer lookup: link, `/me`, `/by-phone/:phone`, `/by-email/:email` (Firebase-auth protected) |
| `accessories.ts` | Accessories catalog |

### Middleware: now **two auth paths**

- `firebaseAuth.ts` — `verifyFirebaseIdToken`: Firebase ID token verification (mobile clients).
- `auth.ts` — `authenticateToken` + `requireRole(['admin'|'employee'|...])`: admin **JWT** + RBAC (admin web dashboard).

Endpoints are now explicitly tiered: public (auth/catalog-public/sdui/serviceability/home-cms),
Firebase-token (mobile), and admin-JWT + role (`requireRole`) for management routes.

### Services (8)

`firestore.ts` (now with `ignoreUndefinedProperties` + undefined-safe write helpers),
`notificationService.ts` (FCM), `catalogService.ts`, `userService.ts`, `employeeService.ts`,
`earningsService.ts`, `razorpay.ts`, `sduiService.ts`.

### API shape & correctness

- Standardized `{ success, data }` envelope across the API (`refactor db45c4d`).
- Firestore custom DB id `safecom-database-nosql` + `FIRESTORE_DB_ID` env override.
- Booking flow: booking advance recorded (`amountPaid`/`totalAmount`), invoice math made
  consistent (advance shown **included** in total; remaining = total − advance).
- Jobs now carry the customer's custom message (`invoice.customTextBox`) end-to-end.
- `PATCH /customers/:id` allows customers to update their **own** profile (was admin-only 403).
- Payment verification now **requires** the Razorpay signature; null signature handled.

## 4. Customer App Changes (`mobile_customer`, Flutter + Riverpod + GoRouter)

### Architecture shift: **Guest-First** browsing
Only `payment`, `confirmation`, `profile`, `order-history`, `booking-detail`
require authentication. Service discovery, estimates, scheduling, and
recommendations are fully public. After login, users without a saved phone are
redirected to a **phone collection** screen (email is now **optional**).

### New/changed screens
- **Dynamic service screen** — one screen renders any service from the backend
  tree (replaces per-service placeholders); clubbed products, branches, nested
  selection popups, quantity/dependency engine.
- **Cart screen** — universal "Add Instructions / Request" field; message flows
  through payment → confirmation → booking → job → employee → admin.
- **Products discovery**, **AMC plans**, **maintenance package selection**,
  **maintenance customization**, **installation customization**, **repair
  estimate**, **upgrade estimate**, **accessories estimate**, **recommendation**,
  **scheduling**, **address list/form**, **about**, **order history**, **booking detail**.
- Map picker integrated into the address form (captures lat/lng).
- Splash, phone-auth, phone-collection, login, location-permission screens.

### UI / Branding
- Premium **light theme** with warm amber (`#D4760A`) + slate/ink (`#0F172A`)
  palette; unified `AppColors` tokens; SafeCom logo widget.
- SDUI engine extended: promo banner with `hideWhenServiceable`, dynamic layouts,
  feature flags, component registry.

### Behavior fixes (May–Aug)
- Phone persistence; booking advance math; custom-message visibility; internal
  product keys hidden from customers; GST-inclusive pricing; Android
  auto-backup disabled (`allowBackup=false` + guard test) so uninstall clears data.
