# Mobile Employee Plan

- Authentication and role guard.
- Job list and job detail.
- Status updates and proof upload.
- Offline queue for status sync.

- Location picker/search for job site confirmation.
- Map pin drop and navigation handoff.
- Job lifecycle enforcement and audit trail sync.
- Earnings history pulled from backend invoices/payments.

- Real-time new-booking notification to employees.
- Full backend job feed integration from customer-created bookings.
- Google Maps deep-link handoff using destination pin coordinates.
- Job-level invoice view with all products/add-ons/quantities/totals.
